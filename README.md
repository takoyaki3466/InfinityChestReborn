# InfinityChest Reborn

**なんだかなつかしい20億チェスト**

丸石があふれた倉庫も、チェストが何十個も並んだ採掘拠点も、これ1つで片付く！
1.7.10時代の名作Mod「InfinityChest」（作者: takanasayo氏）を、Minecraft 1.21.1で遊べるようにした非公式の移植版です。

## できること

- **1種類を20億個まで収納**：ラージチェスト約58万個分が、ブロック1つに収まります。
- **中身がひと目でわかる**：ガラスのチェストの中に、しまったアイテムが飾られます。
- **見るだけで個数がわかる**：チェストに照準を合わせると、面に個数が表示されます。
- **中身ごと持ち運べる**：壊してもアイテムの中に中身が残り、別の場所に置けばそのまま使えます。
- **ホッパーで自動化**：上や横から入れて、下から抜き取れます。

## 対応環境

| Minecraft | ローダー | バージョン |
|:--|:--|:--|
| 1.21.1 | NeoForge | 21.1.80 以上 |
| 1.21.1 | Forge | 52.0.28 以上 |
| 1.21.1 | Fabric | Loader 0.16.9 以上（[Fabric API](https://modrinth.com/mod/fabric-api) が必要） |

## 導入方法

1. お使いのローダーをインストールします。
2. ローダーに合ったこのModのJarファイルを、`mods` フォルダに入れます。
3. ゲームを起動すれば完了です。

マルチプレイでは、サーバーと参加する全員に導入してください。

## 使い方

チェストを右クリックすると画面が開きます。
下段中央が**入れる場所**、下段右が**取り出す場所**です。

### アイテムを入れる

| 操作 | 結果 |
|:--|:--|
| 持っているアイテムを「入れる場所」に左クリック | 全部入れる |
| 持っているアイテムを「入れる場所」に右クリック | 1個だけ入れる |
| 持っているアイテムを「入れる場所」にShift+クリック | 持っている分に加えて、インベントリ内の同じアイテムも全部入れる |
| インベントリのアイテムをShift+クリック | そのスタックを入れる |

### アイテムを取り出す

| 操作 | 結果 |
|:--|:--|
| 「取り出す場所」を左クリック | 1スタック取り出す |
| 「取り出す場所」を右クリック | 1スタックの半分を取り出す |
| 「取り出す場所」をShift+クリック | 1スタック分をインベントリへ移す |
| チェストと同じアイテムを持って、インベントリのスロットをShift+クリック | 持っている分をチェストへ戻し、インベントリの空きをチェストの中身で埋める |

### クリエイティブモード

画面左上のアイテム表示をクリックすると、個数を直接増減できます。

| 操作 | 結果 |
|:--|:--|
| 左クリック / 右クリック | 64個増やす / 減らす |
| Shift+左クリック / Shift+右クリック | 1億個増やす / 減らす |

## 知っておいてほしいこと

- **爆発には注意！** プレイヤーが壊したときだけ中身が残ります。爆発などで壊れると、チェストも中身も失われます。
- 手で入れられるのは、素のアイテムだけです。耐久値が減った道具、エンチャント付きのもの、名前を付けたものなどは入りません。通常のポーションは入れられます。
- 満杯のチェストにホッパーなどで入れると、入りきらない分はその場にあふれ出ます。
- 中身入りのチェストを持つと、画面下に中身と個数が表示されます。

## 他のModと一緒に使うとき

他のModが追加した同じ素材は、同じアイテムとしてまとめて入れられます。たとえば、Aという Mod の銅インゴットが入ったチェストに、Bという Mod の銅インゴットも入れられます。入れたものはチェストに先に入っていたアイテムにそろいます。

この動作を切りたいときは、`config/infchest_reborn.properties` の `doOreNameConvert` を `false` にしてください。
